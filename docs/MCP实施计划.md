# MCP 实施进度

## 已确认架构

Agent 本地审查图片，通过通用上传客户端向 API 传输文件；远程 MCP 使用 Streamable HTTP，负责查询、链接获取和重新处理。生产部署通过 HTTPS 反向代理访问。

## 边界

- 首版使用手动配置 Bearer 集成令牌，不提供 OAuth 授权服务器。
- MCP 不读取 Agent 本地路径，文件由本地工具通过 API 上传。
- 视觉审核由 Agent 执行，服务端没有强制审核门禁。
- 公开图片链接继续沿用公开访问机制。
- 不开放 MCP 删除图片、管理用户、任意网址抓取能力。
