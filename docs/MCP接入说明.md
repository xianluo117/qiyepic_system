# Agent 与远程 MCP 接入说明

## 1. 使用流程

1. 其他项目生成图片，Agent 使用本地视觉能力审查。
2. Agent 查询 MCP 上传规范。
3. Agent 在终端调用[本地上传工具](../tools/image_upload.py)，上传文件内容。
4. 保存每张图片的 ID，使用 MCP 查询状态；间隔至少 2 秒，最多等待 120 秒，超时保留 ID 后续继续查询。
5. 处理成功后调用链接工具；必要时再次审查处理图。

上传成功不等于处理成功。重新处理会改变当前版本。审核是 Agent 流程约束，不是服务器强制门禁。

## 2. 部署配置

在服务器环境配置中设置：

- MCP_ENABLED=true：启用远程 MCP。
- PUBLIC_BASE_URL=https://你的图床域名：仅包含协议、域名及可选端口，不含路径。
- APP_ENV=production：生产环境强制要求 HTTPS 公开地址。

更新依赖、执行数据库迁移并重启服务。容器启动入口已执行迁移；已有部署需要重新构建或拉取包含本次代码的新镜像。仅设置环境变量不会更新镜像代码。

连接地址为公开域名后加 /mcp/，末尾斜杠不可省略。上传仍使用 /api/images/upload。服务端自定义 API 前缀时，以 MCP 上传规范返回的路径为准。

已更新[容器代理配置](../deploy/docker/nginx.conf)与[独立代理配置](../deploy/nginx/image-system.conf)。HTTPS 证书仍由外层代理配置；外层必须保留原始 Host、Authorization、Origin 和 MCP 协议请求头。不要将后端端口直接暴露到公网。不要缓存 MCP 响应。

## 3. 创建集成令牌

首版通过现有 API 文档页面操作，未增加前端令牌管理页面：

1. 使用需要绑定的用户登录，通过登录 API 获得人员登录令牌。
2. 在 API 文档页面授权，调用 POST /api/integration-tokens。
3. 请求填写名称、权限集合和有效天数。例如名称 project-a，权限 images:read、images:upload，有效期 90 天。
4. 保存响应中的完整令牌，只在创建响应显示一次。服务端仅保存摘要。
5. GET /api/integration-tokens 查看自己的令牌；DELETE /api/integration-tokens/令牌ID 撤销。

权限：

| 权限 | 用途 |
|---|---|
| images:read | 连接 MCP、查询图片及版本、获取链接 |
| images:upload | 通过 API 上传文件 |
| images:reprocess | 通过 MCP 重新处理图片；连接 MCP 还需要读取权限 |

令牌继承所属用户的数据范围，不能绕过图片所有者和主管规则。令牌不能签发新令牌、删除图片或管理用户。每个项目单独创建令牌；用户停用、令牌过期或撤销后，后续请求拒绝访问。已开始执行的请求不会被撤销操作中断。

## 4. Agent 的 MCP 连接

在开发助手中选择 Streamable HTTP，地址填写公开域名后加 /mcp/，认证请求头使用 Authorization: Bearer 加集成令牌。

使用客户端的秘密变量或凭证配置，不把令牌写入提示词、聊天内容或提交到代码仓库。本服务采用预配置 Bearer 令牌，不提供 OAuth 授权服务器；客户端必须支持自定义认证请求头。

可用工具定义见[工具模块](../backend/app/mcp/server.py)：

| 工具 | 用途 |
|---|---|
| upload_instructions | 返回上传路径、字段、格式、大小限制 |
| search_images | 货号、文件名分页查找图片 |
| get_image | 通过图片 ID 查询状态和错误 |
| get_image_links | 原图、缩略图、当前或指定版本处理图链接 |
| list_image_versions | 最近 10 个处理版本 |
| reprocess_image | 修改比例、短边后提交重新处理 |

工具失败同时返回 MCP 错误标记和结构化错误详情。新增工具后，客户端可能需要重新连接或刷新工具列表。重新处理为写操作，不应无条件自动重试。

## 5. 本地上传工具

本机需要 Python 3.11 及以上和 httpx，独立依赖见[上传工具依赖](../tools/requirements.txt)。

由用户或凭证系统向 Agent 进程注入：

- QIYE_IMAGE_BASE_URL：HTTPS 图床基础地址。
- QIYE_IMAGE_TOKEN：集成令牌。

运行[上传工具](../tools/image_upload.py)并传入图片路径、货号、比例宽高和最小短边。参数名称见该工具的帮助输出。工具逐张上传，标准输出返回 JSON；退出码 0 表示所有图片均已接收，非 0 表示至少一张失败。

工具默认限制单图 30 MB，服务端可能配置不同限制。不要关闭证书验证，不自动跟随重定向，凭证不应出现在命令参数中。

收到传输结果不确定标记时，先通过货号和文件名查询服务器，核对图片及状态，禁止直接重复上传。服务器当前拒绝同一员工、同一货号的同名文件，但尚未提供请求幂等键；查询也不能替代内容摘要一致性校验。

## 6. 链接与状态

处理状态：pending、processing、success、failed。成功后才可获取新处理版本。重新处理期间可能仍存在旧版本链接，不能将旧链接误认为本轮处理结果。

集成链接包含图片 ID，避免同名不同扩展名冲突。现有不含 ID 的业务链接继续保留。返回的图片链接是公开链接，持有者无需令牌即可访问。

## 7. 上线验收

- 配置实际 HTTPS 域名，确认代理未丢失认证与协议头。
- 真实 Agent 连接并发现工具。
- 审查一张图片，通过本地工具上传。
- 实际任务队列处理完成，MCP 返回可访问的正确版本链接。
- 撤销令牌后，上传与 MCP 查询均被拒绝。

本地自动化测试不代替以上生产验收。
