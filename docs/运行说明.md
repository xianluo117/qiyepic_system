# 开发与运行说明

## 0. 当前本机试运行

开发服务已验证可运行：

```text
前端：http://127.0.0.1:1230
后端：http://127.0.0.1:1231
接口文档：http://127.0.0.1:1231/docs
```

管理员账号不在源码中提供默认值。首次启动前必须在 `backend/.env` 中配置：

```text
BOOTSTRAP_ADMIN_USERNAME=自定义管理员用户名
BOOTSTRAP_ADMIN_PASSWORD=至少 12 位的强密码
BOOTSTRAP_ADMIN_EMPLOYEE_ID=自定义管理员员工 ID
```

同时必须配置不少于 32 个字符的 `SECRET_KEY`。`backend/.env` 仅用于本机运行，并已被 Git 忽略，不得提交到代码仓库。

本机没有安装 MySQL 和 Redis，因此 `backend/.env` 临时采用：

- SQLite 数据库；
- Celery eager 同步任务模式；
- `backend/runtime/images` 本地图片目录。

Linux 正式部署时按本文后续章节切换到 MySQL、Redis 和异步 Celery Worker。

## 1. 环境要求

- Python 3.11 或更高版本；
- Node.js 22 或当前维护中的 LTS 版本；
- MySQL 8；
- Redis 7；
- Linux 生产服务器使用 Nginx 和 systemd。

## 2. MySQL 初始化

创建数据库和应用账号：

```sql
CREATE DATABASE image_system
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

CREATE USER 'image_system'@'127.0.0.1'
  IDENTIFIED BY '请替换为强密码';

GRANT ALL PRIVILEGES ON image_system.*
  TO 'image_system'@'127.0.0.1';

FLUSH PRIVILEGES;
```

生产环境应根据实际连接来源调整 MySQL Host 授权范围。

## 3. 后端开发环境

进入 `backend` 目录后创建 Python 虚拟环境并安装项目依赖。

将项目根目录的 `.env.example` 复制为后端工作目录可读取的 `.env`，然后设置密钥、管理员账号、管理员强密码、数据库密码和图片根目录。缺少这些必填配置时，后端会拒绝启动。

执行数据库迁移：

```text
alembic upgrade head
```

启动 FastAPI：

```text
uvicorn app.main:app --reload
```

启动 Celery Worker：

```text
celery -A worker.celery_app:celery_app worker --loglevel=INFO
```

健康检查地址：

```text
http://127.0.0.1:1231/health
```

## 4. 前端开发环境

进入 `frontend` 目录安装依赖并运行：

```text
npm install
npm run dev
```

开发服务器默认使用 1230 端口，并将 `/api` 请求代理到本机 1231 端口。

## 5. 图片目录

默认根目录：

```text
/data/image-system
```

运行 FastAPI 和 Celery 的 Linux 用户必须拥有该目录的读取、创建和写入权限。

## 6. 生产部署

建议目录：

```text
/opt/image-system/backend
/opt/image-system/venv
/opt/image-system/frontend-dist
/opt/image-system/config/backend.env
/data/image-system
```

部署步骤：

1. 安装 MySQL、Redis、Nginx、Python 和 Node.js；
2. 创建独立 Linux 用户 `image-system`；
3. 创建应用目录与图片目录并设置权限；
4. 将后端代码部署到 `/opt/image-system/backend`；
5. 创建虚拟环境并安装后端依赖；
6. 配置 `/opt/image-system/config/backend.env`；
7. 执行 Alembic 数据库迁移；
8. 构建 Vue，将 `frontend/dist` 部署到 `/opt/image-system/frontend-dist`；
9. 安装 systemd 服务文件；
10. 安装 Nginx 站点配置；
11. 启动 FastAPI、Celery、Nginx；
12. 配置 HTTPS、数据库备份和图片目录备份。

### 7.1 放大清晰度处理

图片短边不足时，处理器按以下顺序执行：

1. 以每阶段不超过 2 倍的尺寸使用 Lanczos 插值放大；
2. 最后一阶段精确缩放至目标尺寸；
3. 仅对放大结果应用轻度 `UnsharpMask` 锐化；
4. JPEG 和 WebP 使用 95 质量保存，JPEG 禁用色度抽样以减少边缘损失。

锐化参数固定为：

```text
radius=1.2
percent=110
threshold=3
```

该方案用于减少普通插值放大后的柔化感，不会对无需放大的图片进行锐化。它不能恢复原图中已经缺失的纹理、文字或真实细节；原图分辨率过低或放大倍率过高时，仍会存在画质上限。
